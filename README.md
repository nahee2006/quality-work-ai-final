# data10-09 · 품질보증팀 업무 경험 수집 및 AI 기반 디지털 업무 자료화

기존 업무자료(절차서 · 지침서 · 체크리스트 · 기록 양식 · 시스템 입력 항목 · 업무 순서 자료 · 캡처)와 담당자의 설명 · 경험(암묵지)을 모아, AI 로 **업무 프로세스 흐름도와 단계별 업무 방법서 초안**을 만드는 브라우저 도구. 단계마다 근거(문서 / 담당자 답변 / AI 추정)와 「담당자 확인」을 보이고, 업무 방법서 · 단계표 · 인수인계 체크리스트 · 1장 요약으로 냅니다.

> 과제는 패들릿으로 접수했습니다. 실제 업무 자료는 아직 받지 않았고(기획서 「방향 수정」 확인 목록), 샘플 「수입검사 부적합품 처리」의 절차서 · 체크리스트 · 시스템 입력 항목 · 화면 그림 · 담당자 답변 · AI 답은 일반적인 제조업 품질보증 업무로 새로 지은 **가상 값**입니다(문서번호 · 메뉴 · 수치 포함). 소속 회사명은 리포에 두지 않습니다.

## 실행 방법

**온라인에서 바로 보기: https://data10-09.jobability.co.kr/** (로그인 · 승인 뒤 사용 — 아래 「로그인 · 승인」)

처음 열면 「① 자료 등록하기」 화면입니다. **「샘플로 해 보기」** 를 누르면 가상 「수입검사 부적합품 처리」(자료 3 · 화면 그림 1 · 답 11/13 · 말로 한 설명 1 · AI 초안 v1)가 들어갑니다. ③ 화면의 「샘플 AI 답 넣기」로 AI 없이도 답 읽기 → 새 판 저장까지 해 볼 수 있습니다.
파일 · 사진 · 답변은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다. AI 에는 사람이 복사한 프롬프트만 들어가고, 설정에서 사내 OpenAI 호환 서버를 적은 경우에만 「자동 보내기」가 됩니다.

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀 · docx 읽기는 `vendor/` 의 SheetJS — docx 는 그 안의 zip 읽개로 `word/document.xml` 만 풂).

| 화면 | 하는 일 |
|---|---|
| ① 자료 등록하기 | 업무 만들기(업무 목록에서 고르기 가능 — **「업무 목록 파일로 바꾸기」로 샘플 52개 대신 내 파일 목록, 「업무 목록 비우기」**) · 자료 붙여 넣기 · txt(UTF-8/EUC-KR) · docx(문단 · 표) · xlsx(시트마다) — PDF · 한글은 글자 복사 안내 · 자료 종류 짐작 · 고치기 · 전에 만든 흐름도를 「업무 순서 자료」로 · 캡처 · 사진(큰 사진은 1600px 로 줄여 IndexedDB, AI 에는 설명만) · 자료 번호 M1 · P1 |
| ② 담당자에게 질문하기 | 기본 질문지 13개(순서 · 판단 기준 · 수치 · 예외 · 실수 · 주의 · 양식 · 시스템 화면 · 소요시간 · 넘기는 곳) · **AI 로 질문 뽑기**(자료와 실제가 다른 곳, 겹치는 질문 뺌) · 질문마다 답 저장(여러 번에 나눠) · 답 없는 것만 보기 · 질문지 인쇄 · **말로 한 설명 붙여 넣기**(T1) |
| ③ AI 초안 작성 | 자료 + 답변 + 설명 + 사진 설명 + 「못 받은 질문」을 묶은 프롬프트(요청형, 「지어내지 말고 더 확인할 것으로」) → 답(JSON) 붙여 넣기 → 검사(``` · 끝 쉼표 · 끊김 · 없는 근거 id · 흐름 고리) → **흐름도**(판단은 마름모) + **단계별 업무 방법서**(누가 · 입력 · 방법 · 기준 · 예외 · 주의 · 양식/시스템 · 시간) · 단계마다 근거 **문서 / 담당자 / 둘 다 / AI 추정** · 칸 단위 「AI 추정」 · 근거 사진 · **담당자 확인** · 단계 고치기(새 판) · 판 기록 · 「더 확인할 것」→ 담당자 질문 |
| ④ 문서로 내보내기 | Word 업무 방법서(흐름도 그림 · 근거 사진 포함) · Excel 단계표(단계표 · 근거 자료 · 용어 · 더 확인할 것 · 체크리스트 5시트) · 인수인계 체크리스트(인쇄 · Excel) · 1장 요약(인쇄 · Word) · 흐름도 SVG · PNG · **「⑤ 신입 교육 자료로 보내기」** |
| ⑤ 신입 교육 자료 만들기 | ④ 에서 보낸 초안 흐름으로 교육 한 장(목적 · 흐름도 · 핵심 포인트 · 자주 하는 실수 · 확인 퀴즈 3문항, 인쇄 · Word) · AI 로 교육 한 장 초안 · 난이도 · 「교육에 넣기/빼기」 · 주차별 커리큘럼(인쇄 · 엑셀) |
| 설정 | 신입 교육 기간 · AI 연결(OpenAI 호환 주소 · 모델 · 본인 키, 기억은 선택) · JSON 백업(사진 포함) |

- **11-10 메뉴 정리**: 「기존 도구 (1단계)」의 업무 목록 가져오기 · 핵심 업무 선정 · 문서 맵 · 업무 흐름도는 신규 기능과 겹쳐 메뉴에서 뺐습니다. 저장된 자료는 그대로이고 화면 코드는 남겨 주소(`#/import` · `#/core` · `#/docs` · `#/flow`)로만 열립니다. 업무 목록은 ① 화면의 「업무 목록 파일로 바꾸기」로 넣습니다.
- **신입 교육 위치(11-10 확인 요청에 대한 답)**: 신입 교육 화면은 ③ 에서 확인한 초안의 **흐름**을 재료로 씁니다(흐름도 · 핵심 포인트 · 퀴즈가 모두 그 흐름에서 나옴). 그래서 1~4번 흐름 안에 섞지 않고 **흐름 뒤 ⑤ 번**으로 두었습니다 — 업무 방법서가 먼저 확인돼야 교육 자료가 틀리지 않고, 신입 교육이 필요 없는 업무는 ④ 에서 끝내면 됩니다.

- 로직 테스트: `node test/capture.test.mjs`(업무 자료화 21개) · `node test/logic.test.mjs`(업무 목록 · 흐름도 · 신입 교육 39개) — 의존성 없음
- **업무 목록 바꾸기(10-28 수강생 요청)**: 합치지 않고 파일의 업무만 남깁니다. 필수 열은 업무명 하나(주기 · 소요 시간 · 직책 · 구분 · 관련 문서는 선택), 제목 줄 없는 한 열 목록도 읽음, 같은 이름은 한 번만. 지워지는 것은 옛 업무에 딸린 1단계 흐름도 · 교육 한 장 · 핵심 선택 · 문서 연결(샘플이면 가상 문서와 샘플 표시까지)이고, 업무 자료화(자료 · 인터뷰 · 초안 · 사진)는 남습니다 — 확인 창에 둘 다 보입니다
- **판 올리기(고칠 때마다)**: `node scripts/bump-version.mjs 2026-10-28.1` — index.html 의 모든 js·css `?v=` · logic.js · capture.js · app.js 를 같은 값으로. 섞이면 화면이 「새 판이 나왔습니다 — 새로고침(Ctrl+F5)」로 멈춥니다. `--check` 로 같은지만 봅니다
- 브라우저 점검(선택): `PLAYWRIGHT_CORE=<playwright-core 경로> [CHROME_PATH=<크롬 실행 파일>] node scripts/check-capture.mjs` — 옛 판 자료 옮기기 · 망가진 자료 · 샘플 한 바퀴 · 파일 넣기 · 흐름도 글자 실측 · 내보내기 · 백업 · 4가지 폭 가로 넘침 · JS 오류. 1단계 화면은 `scripts/check-browser.mjs`
- 샘플 엑셀 다시 만들기: `node scripts/make-samples.js` · 기획서 Word: `python3 scripts/make-docx.py`

## 로그인 · 승인

1. https://data10-09.jobability.co.kr/ 에서 **회원가입** — 회사 메일이나 개인 메일 + 비밀번호(카카오 로그인도 됨)
2. 가입 뒤 **사용 신청**(이름 · 연락처 · 소속)
3. **관리자 승인** 뒤에 도구가 열립니다. 처음 관리자는 과정 운영 계정이고, 요청자를 관리자로 올리면 요청자가 자기 팀원을 승인합니다(회원 표 `data1009_members`).

- 내 PC(`localhost` · 파일로 열기)에서는 로그인을 건너뜁니다. 주소 끝에 `?auth=1` 을 붙이면 내 PC 에서도 로그인 대문을 볼 수 있습니다.
- 업무 자료는 로그인과 상관없이 **이 브라우저에만** 저장됩니다(서버로 보내지 않음). 로그인 정보만 Supabase 에 있습니다.
